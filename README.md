# Save Reminder

[![Python version][python_version_badge]](#)
[![Pyttsx3 version][pyttsx3_version_badge]](#)

Lightweight reminder that plays an audio alert every five minutes.

Inspired by a videogame that crash unexpectedly and lack an autosave feature, **Save Reminder** helps you avoid losing progress by reminding you to save frequently.

## Running from executable
If you download the latest release, you can run it using the executable file.

## Running from source
Before running **Save Reminder**, you need to install its dependencies. You can do this easily with pip:
```
pip install -r requirements.txt
```

Once the installation is complete, you can run **Save Reminder** directly with Python:
```
python save_reminder.py
```
